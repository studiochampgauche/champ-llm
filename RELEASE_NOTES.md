# Release notes

## Current development version

- Configurable Llama-style model creation, with size presets, custom dimensions
  and parameter/memory planning.
- Text and code preparation, custom tokenizer training, pretraining and
  conversation fine-tuning.
- Checkpoints containing the state needed to resume training.
- Direct local inference and an optional Ollama backend for the coding agent.
- Website inspection through Chromium, Google Chrome, Firefox and WebKit.
- Experimental training on annotated screenshots and code.

See [Getting started](GETTING_STARTED.md) for setup,
[Model configuration](docs/MODEL_SIZES.md) for architecture options, and
[Validation](docs/VALIDATION.md) for tested behavior and remaining limitations.
